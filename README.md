## 🧑‍💻 About Me

> **"비즈니스 가치를 이해하고, 주도적으로 서비스를 완성합니다."**

안녕하세요! **React 생태계**를 기반으로 직관적인 UI/UX를 설계하는 프론트엔드 개발자입니다.
단순히 화면만 그리는 것이 아니라, **FastAPI/Spring Boot 백엔드**와 **최신 AI 기술(LLM, Vision)**을 융합하여 실제 서비스로 구현해낸 경험이 있습니다.

- 🤝 **Communication:** 풀스택 개발 경험을 바탕으로 백엔드/AI 팀원과 원활하게 소통하며 협업합니다.
- 🚀 **Challenge:** 새로운 기술(AI Agent, YOLO)을 두려워하지 않고, 서비스에 적합하게 응용하는 것을 즐깁니다.
